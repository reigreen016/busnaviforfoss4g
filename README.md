# busnaviforfoss4g

広島駅からFOSS4Gの4会場へ向かうバスのサイネージ。元リポジトリ https://github.com/reigreen016/busnavi を複製し、南口案内画像と位置情報を引き継いでいます。元画面は original.html に保存しています。

## ローカルで開く

このフォルダで `npm start`（または `python3 -m http.server 8000 --bind 127.0.0.1`）を実行し、http://127.0.0.1:8000 を開きます。Python 3が必要です。外部パッケージのインストールは不要です。

会場タブで切り替えます。「表示日時・データについて」から日付・時刻を指定できます。会場を切り替えると開催日（初日）が選択され、開催日選択から各日へ切り替えられます。時刻は日本時間の現在時刻で15秒ごとに更新します。先頭20便を出発順に表示します。

## データの更新

`python3 scripts/build_data.py /path/to/GTFSのZIPフォルダ`

提供された4社のZIPから data/timetable.json を生成済みです。ZIPは元の場所から読み取り、変更していません。出発停留所は南口の「広島駅」の完全一致です（東広島駅・西広島駅は対象外）。系統番号で制限せず、stop_sequenceの順序、乗車・降車可否で直通便を抽出し、会社ごとにservice_idを区別します。運行カレンダーとcalendar_datesの追加・削除、前日運行の24時超の便に対応します。同じ便が複数の対象停留所に停車するときは、最初に到着する対象停留所を表示します。循環便など所要時間の長い便も含み、所要時間を明示します。

有効期間：広島バス 2026-10-09～2027-04-09、広島電鉄 2026-10-27～2027-04-27、広島交通 2026-10-10～2027-04-10、JRバス中国 2026-10-25～2027-04-25。会議当日の時刻表が有効期間内か確認し、必要なら最新GTFSで再生成してください。

乗り場番号はstops.txtのplatform_codeを使用し、欠損時は推測しません。南口地図は元リポジトリの画像と手動定義位置のため、現地の最新案内と照合が必要です。北口（新幹線口）発は抽出対象外です。時刻は予定時刻で、遅延・運休のリアルタイム情報は含みません。徒歩ルートは外部のGoogleマップリンクです。

`npm test`（Node.js 18以降）。運行日例外、平日・土曜・日曜の全会場の便、深夜便を検証します。

提供GTFSの有効期間は開催日より後です。そのため画面では参考ダイヤと明記し、有効期間内の2026-11-08（日）〜11-14（土）の同じ曜日の運行日を参照します。当日の確定ダイヤや特別運行を再現するものではありません。有効期間内の日付を指定した場合は、その日のcalendar/calendar_datesを直接使用します。運行カレンダーの判定を有効期間外へ無条件に拡張することはしていません。

## 画面・言語

横長画面では左55%に大型の南口乗り場図、右上に直近便の乗り場カード、右下に発車順の詳細20便を表示します。カードは最初の出発から10分以内の便を乗り場ごとにまとめ、番号の昇順に表示します（カードは番号のみ、発車時刻は下の詳細に表示）。地図の強調も同じ乗り場に対応します。番号未収録は末尾に「—」で表示し、地図上では推測しません。狭い画面では縦に並べます。

日本語・英語・韓国語・簡体字・繁体字に対応します。右上で切り替え、選択をブラウザに保存します。停留所・会社・系統名称・行き先は各社GTFSのtranslations.txt（trans_id/lang/translation形式）から読み込みます。未収録の名称は原文を残します。会場名と画面の操作文言はアプリ内の翻訳です。乗り場図は元画像のままで、主に数字の案内です。

公式サイト https://2026.foss4g.org/ja/ を参考にArchivo・Interのフォントと赤を基調にしました。Google Fontsへ接続できない場合はシステムフォントを使用します。GTFSデータは同梱済みのため外部から取得しません。

更新後、ブラウザで左右レイアウトと5言語の停留所表示を確認済み。自動テスト8件通過。

地図の強調は小さめの番号と赤い光のアニメーションで表示します。動きを減らす設定の場合は静的な発光になります。発車案内は各便に下車停留所を明記し、淡い赤の枠で区別します。

ヘッダーは提供ロゴと「busnavi / BUS GUIDE」を並べて表示します。下車停留所は会場名の隣に集約し、候補が複数の会場では各便の到着情報に停留所名だけを併記します。時刻と乗り場番号はArial / Helveticaを使用します。

発車まで0〜180秒の便は、元のbusnaviと同じsoonGlow（1.2秒周期、薄黄色から黄色、影10〜30px）で行全体を強調します。動きを減らす設定では静的な黄色で表示します。3分の境界判定を含むテスト9件通過。

発車3分以内の行は赤系の発光に変更（1.2秒周期と影10〜30pxは維持）。英数字はFrutiger / Frutiger LT Pro / Frutiger Neueを優先します。フォントファイルは同梱しておらず、端末にない場合はArial / Helveticaなどで表示します。

最新の表示設定：英数字はHelvetica優先。地図は元版と同じ1000msごとの濃淡切り替え（背景0.9/0.2、濃い時の光8px、背景変化0.3秒、倍率1.15）。色は淡い赤に調整し、発車3分以内の行の赤も薄くしています。

地図は濃淡切り替えから、前のゆっくり光が広がる効果（1.8秒の往復）に戻しました。下車停留所は左カラムの右端に配置し、会場名と上下の中心を揃えています。
